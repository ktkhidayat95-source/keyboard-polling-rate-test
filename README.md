## What Is Keyboard Polling Rate?

Keyboard polling rate is the number of times per second your keyboard sends input data to your computer.

Common polling rates include:

| Polling Rate | Response Time |
|--------------|--------------:|
| 125 Hz | 8 ms |
| 250 Hz | 4 ms |
| 500 Hz | 2 ms |
| 1000 Hz | 1 ms |

Higher polling rates reduce input delay, which is especially useful for gaming and competitive typing.
